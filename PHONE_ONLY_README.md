# Dreamy SRL v1.3 — Phone-only test

This build runs entirely in a modern phone browser and requires:
- no laptop
- no ComfyUI
- no Ollama
- no paid API
- no backend server

It procedurally renders an original dreamy double-stack composition in-browser using Canvas.

## Test
Open the GitHub Pages site for this repository after Pages is enabled from the main branch root.

## Included
- description field
- proportional inch sizing
- deterministic procedural dreamy rendering
- SRL signature
- PNG / JPG / WEBP / PDF export
- downloadable component canvases
- PWA manifest/service worker

## Limitation
This is a phone-only visual test engine, not a neural diffusion model. The local ComfyUI build remains the higher-fidelity generation path.
